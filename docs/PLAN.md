# Lableo 3D
Next.js App Router, TypeScript strict, Tailwind, componentes server e pequenas ilhas interativas. Dados locais substituíveis em src/data; configuração em src/lib/config.ts. Tokens semânticos no CSS. Sem estoque, preços, fotos ou projetos reais: todo conteúdo inicial é demonstração.

Referências consultadas em 18/11/2026: printfoundry.studio (catálogo/encomendas), 3devogue.com (coleções e orçamento), e3dprints.com/collections/3d-prints (busca e catálogo), printmorph.com (categorias e personalização), decorartor.com (navegação por tipos). Consulta estrutural textual, sem inspeção visual dessas páginas. Não reutilizamos ativos.

Contato depende de configuração real. Sem backend ou upload; orçamento preparado localmente para envio pelo visitante. SEO absoluto depende de domínio configurado. Métricas são metas, não garantias.

Validação executada: build de produção, ESLint, TypeScript, cinco testes Vitest e quatro testes Playwright aprovados. Capturas desktop (1440 px) e mobile (375 px) inspecionadas. A primeira execução Playwright encontrou outro serviço na porta 3000; configuração corrigida para servidor dedicado na porta 3107. Labels do formulário corrigidos após validação. Lighthouse e auditoria WCAG completa não executados.
